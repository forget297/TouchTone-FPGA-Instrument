# 万能板焊接接线表

适用：Nano 20K R12 ＋ ESP32-S3固件v06 ＋ App v0.5.0 ＋ TJC8048X550_011C。整理日期：2026-10-16。
**本表只说明实际外接焊线，不把板内时钟、板载LED、板载按键混进焊接清单。现有程序和引脚分配不变。**

看法：先按第1节焊Nano，第2节焊ESP32，第3节焊电源，再按第4～11节逐个模块核对。表中的“＋”表示同一电气节点要同时连到列出的多个端子。
Nano数字指排针对应丝印/FPGA封装脚号，不是从一端数孔位；ESP32使用GPIO丝印；74HC595数字是DIP-16芯片实体脚号。三种编号不要混用。
本表没有假设各模块排针的左右顺序：按端子丝印找VCC/GND/SDA等。芯片脚号按顶视缺口/1脚标记识别，翻到万能板焊接面后位置镜像，先在板上标出1脚再焊。

## 1. Nano 20K排针：往外接什么

| Nano排针丝印 | 直接焊到哪里 | 用途/备注 |
|---|---|---|
| 27 | MPR121的SCL ＋ ADS1015的SCL | 两模块共用同一根SCL网络 |
| 28 | MPR121的SDA ＋ ADS1015的SDA | 两模块共用同一根SDA网络 |
| 29 | EC11的KEY/SW | 编码器按下信号 |
| 30 | 摇杆的SW | 摇杆按下信号 |
| 31 | U1的14脚SER/DS | 595串行数据，保持31，不换55 |
| 41 | EC11的S2/B/DT | 编码器B相 |
| 48 | U1的11脚 ＋ U2的11脚 | 两片595共用移位时钟 |
| 49 | U1的12脚 ＋ U2的12脚 | 两片595共用锁存时钟 |
| 52 | ESP32的GPIO17 | ESP发送→Nano接收 |
| 53 | ESP32的GPIO18 | Nano发送→ESP接收 |
| 54 | ESP32的GPIO6 | I²S音频DATA |
| 55 | ESP32的GPIO5 | I²S左右声道时钟WS，不能用于LED |
| 56 | ESP32的GPIO4 | I²S位时钟BCLK |
| 77 | EC11的S1/A/CLK | 编码器A相 |
| 3V3 | 3.3V公共焊点 | 再从此处分给第3节所列外设 |
| GND | GND公共焊点 | 所有信号模块共地 |

Nano继续用USB供电。54/55/56已在板内连接功放，表中是另外分支到ESP32的数字输入，不需要给板载功放重新拉线。**55已经占用，不能替代31接U1.14。**
Nano25、26不焊外接线，拆除旧排查电阻。Nano74、75是可选测试点，当前迁移不必接。Nano4、15～20、51、87、88是当前板内功能，不需要为本方案额外焊线。
喇叭走板载专用接口，见第11节，不是接54/55/56。

## 2. ESP32-S3排针：往外接什么

| ESP32排针丝印 | 直接焊到哪里 | 用途/备注 |
|---|---|---|
| GPIO4 | Nano的56 | I²S BCLK输入 |
| GPIO5 | Nano的55 | I²S WS输入 |
| GPIO6 | Nano的54 | I²S DATA输入 |
| GPIO8 | 串口屏的RX | ESP TX→屏RX |
| GPIO9 | 串口屏的TX | 屏TX→ESP RX |
| GPIO17 | Nano的52 | ESP TX→Nano RX |
| GPIO18 | Nano的53 | Nano TX→ESP RX |
| GND | GND公共焊点 | 与Nano、屏幕及其他模块共地 |
| 3V3、5V/VIN | 当前方案不与Nano电源脚并接 | ESP32继续USB供电 |

这里GPIO8/9在ESP32上，不是Nano的8/9。屏幕使用UART2，Nano通信使用UART1，两组不能互换。

## 3. 公共电源焊点：分给哪些端子

建议在万能板上明确标出下面三个不同节点；信号GND共用，3.3V和5V不能焊成同一条。

### 3.1 3.3V公共焊点

来源：**Nano的3V3**。分支连接：

| 焊到的对象 | 对象端子 |
|---|---|
| MPR121 | VCC |
| ADS1015 | VDD/VCC |
| FSR压力信号板 | VCC |
| 摇杆 | VCC（已验证无源电位器型，部分板印5V） |
| EC11模块 | VCC/5V电源端（沿用已验证可3.3V工作的模块） |
| 74HC595 U1 | 16脚、10脚 |
| 74HC595 U2 | 16脚、10脚 |

不要再把ESP32的3V3输出并到这条电源。该表沿用当前已验证的3.3V模块，不表示任意印5V的替换模块都兼容。

### 3.2 GND公共焊点

连接Nano GND、ESP32 GND、MPR121 GND、ADS1015 GND、FSR信号板GND、摇杆GND、EC11 GND、屏幕GND、屏幕5V电源的GND；另接U1的8/13脚、U2的8/13脚、ADS1015 ADDR，以及12颗LED阴极。
ADS1015 A3可固定接此GND（推荐，当前不采集）；不要把ADS的ALRT/IRQ或595未用输出当作地。

### 3.3 屏幕5V供电

沿用已验证的稳定5V电源：5V→屏幕VCC，电源GND→公共GND。可以保留USB转TTL的供电与GND，但其TX/RX两根信号必须从屏幕断开。
不要把屏幕VCC接Nano/ESP的3V3，也不额外并联两块开发板的5V/VIN。两块开发板仍分别USB供电。

## 4. MPR121触摸模块：每个排针往外接什么

| MPR121端子 | 直接焊到哪里 |
|---|---|
| VCC | 3.3V公共焊点 |
| GND | GND公共焊点 |
| SCL | Nano27；同一节点也连ADS1015 SCL |
| SDA | Nano28；同一节点也连ADS1015 SDA |
| IRQ | 不接 |

当前是已集成12触摸片的模块，ELE0～ELE11已在模块内连接，不把12个触摸片分别焊到Nano。地址沿用0x5A；当前模块无需额外引出ADDR。

## 5. ADS1015模块：每个排针往外接什么

| ADS1015端子 | 直接焊到哪里 |
|---|---|
| VDD/VCC | 3.3V公共焊点 |
| GND | GND公共焊点 |
| SCL | Nano27；同一节点也连MPR121 SCL |
| SDA | Nano28；同一节点也连MPR121 SDA |
| ADDR | GND公共焊点，地址0x48；沿用原模块地址配置 |
| A0/AIN0 | FSR压力信号板AO |
| A1/AIN1 | 摇杆VRx |
| A2/AIN2 | 摇杆VRy |
| A3/AIN3 | 推荐接GND；固件不采集 |
| ALRT/ALERT/RDY | 不接 |

按模块端子标记接，不按ADS芯片实体脚号接。ADDR若有板载跳线保持原0x48配置，不把原本固定到电源的跳线直接短接地。
SCL/SDA沿用当前模块的上拉到3.3V；已有上拉不重复焊。确认没有上拉时，SCL、SDA才分别增加4.7kΩ到3.3V。

## 6. FSR压力信号板和压力片：往外接什么

| FSR信号板端子 | 直接焊到哪里 |
|---|---|
| VCC | 3.3V公共焊点 |
| GND | GND公共焊点 |
| AO | ADS1015 A0/AIN0 |
| DO | 不接 |
| 专用压力片接口 | FSR本体两根线，保持原模块接口接法 |

压力片先接自己的信号板，信号板AO再接ADC；当前已有转换模块，不另加裸FSR分压电路，也不把AO接Nano数字脚。

## 7. 摇杆模块：每个排针往外接什么

| 摇杆端子 | 直接焊到哪里 |
|---|---|
| VCC/5V电源端 | 3.3V公共焊点，沿用原已验证模块 |
| GND | GND公共焊点 |
| VRx | ADS1015 A1/AIN1 |
| VRy | ADS1015 A2/AIN2 |
| SW | Nano30 |

VRx/VRy是模拟输出，接ADC，不直接接Nano。SW是按下开关，接Nano30。

## 8. EC11编码器：每个排针往外接什么

| EC11模块端子/常见别名 | 直接焊到哪里 |
|---|---|
| S1 / A / CLK | Nano77 |
| S2 / B / DT | Nano41 |
| KEY / SW | Nano29 |
| VCC / 5V电源端 | 3.3V公共焊点，沿用原已验证模块 |
| GND | GND公共焊点 |

EC11的S1/S2是A/B相端子，和Nano板载S1/S2按键不是同一件事。旧Nano25/26不再用。

## 9. 两片74HC595：逐个实体脚往外接什么

下表中的R1～R12只是本焊接表给12只1kΩ电阻的建议标签，不是程序要求；每颗LED一只独立电阻。

### 9.3 两颗去耦电容

| 建议标签 | 器件 | 两端分别焊到 |
|---|---|---|
| C1 | 100nF（104）瓷片 | U1的16脚和8脚 |
| C2 | 100nF（104）瓷片 | U2的16脚和8脚 |

靠近对应芯片，瓷片电容无极性。它们跨接在电源和地之间，不是串进供电线。只装12个琴键灯时U2.4～7留空，不能将这些输出直接接地。

## 10. 12颗LED：每颗两条腿接哪里

每一条完整路径是：**595输出→独立1kΩ电阻→LED阳极；LED阴极→GND公共焊点**。不要共用一只电阻。

| 灯号 | 阳极（+）前串1kΩ后接到 | 阴极（−）接到 | 对应触摸通道 |
|---|---|---|---|
| K1 | U1的15脚，经R1 | GND公共焊点 | ELE0 |
| K2 | U1的1脚，经R2 | GND公共焊点 | ELE1 |
| K3 | U1的2脚，经R3 | GND公共焊点 | ELE2 |
| K4 | U1的3脚，经R4 | GND公共焊点 | ELE3 |
| K5 | U1的4脚，经R5 | GND公共焊点 | ELE4 |
| K6 | U1的5脚，经R6 | GND公共焊点 | ELE5 |
| K7 | U1的6脚，经R7 | GND公共焊点 | ELE6 |
| K8 | U1的7脚，经R8 | GND公共焊点 | ELE7 |
| K9 | U2的15脚，经R9 | GND公共焊点 | ELE8 |
| K10 | U2的1脚，经R10 | GND公共焊点 | ELE9 |
| K11 | U2的2脚，经R11 | GND公共焊点 | ELE10 |
| K12 | U2的3脚，经R12 | GND公共焊点 | ELE11 |

LED长腿通常为阳极、壳体平边通常为阴极；已剪脚就用二极管档确认。K1对应ELE0、K9对应ELE8；商家触摸片外观排列可能不同，应沿用已经实测的ELE标签。
改键位音高不改变灯与实体触摸通道的对应关系。普通演奏只跟实体触摸亮灯；App无线演奏不点这些灯。曲谱指引只亮目标，不叠加触键灯，暂停/休止/拍尾可能全灭。

## 11. 串口屏和喇叭：接口往外接什么

### 11.1 TJC8048X550_011C串口屏

| 屏幕端子 | 直接焊到哪里 |
|---|---|
| VCC/5V | 已验证的稳定5V电源正极 |
| GND | GND公共焊点 |
| RX | ESP32 GPIO8/TX |
| TX | ESP32 GPIO9/RX |

以屏幕丝印为准，不假定四针从左到右的顺序。USB转TTL的TX/RX不再接屏幕，不能与ESP双发送端并接。
屏幕HMI保留page0/s0、760×200、0通道；无需为从面包板迁移而改屏幕工程。

### 11.2 喇叭

板载喇叭专用接口（J4）的SPEAKER_P/OUTP→喇叭正端，SPEAKER_N/OUTN→喇叭另一端。沿用现有匹配接口线。
喇叭两端都是功放输出，不接公共GND，不接ESP GPIO，不接Nano54/55/56。

## 12. 焊接时按组核对

- [ ] 先确认插座/芯片1脚；焊接面是顶视图的镜像，不按模块物理左右位置猜端子。
- [ ] 3.3V公共点和GND分支齐全；屏幕5V独立；两个开发板电源输出不并联。
- [ ] I²C：27→两个SCL，28→两个SDA；ADC模拟线只接A0/A1/A2。
- [ ] 编码器77/41/29，摇杆开关30；旧25/26不焊。
- [ ] LED三线31/48/49、U1.9→U2.14；两片8/13接地、10/16接3.3V，各有100nF。
- [ ] K1～K12各有独立1kΩ，阴极共地；U2.4～7和9不短接地。
- [ ] ESP：17→Nano52、18→Nano53；4→56、5→55、6→54；8→屏RX、9→屏TX。
- [ ] 断电通断档排查相邻焊点桥连及电源对地明显短路；供电时先确认3.3V和屏幕5V，再下载程序验收。

通断/电阻档只在断电状态使用。万能板不像面包板自动按孔组连通，按所用板型的铜箔结构逐条焊接/跨线并核对。
Nano若因迁移断电，重新上电后需重新下载R12到SRAM；S2复位会清除临时键位和曲谱。旧版固件和接线不要混用。
